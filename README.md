# Book Tracker

A small responsive Book Tracker web app built with HTML, CSS and JavaScript.

## Features
- Add books
- Edit books
- Delete books
- Track To Read / Reading / Completed
- Search by title or author
- Filter by status
- Dashboard statistics
- Saves data in browser localStorage
- Responsive design

## Run locally
Open `index.html` in a web browser.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `book-tracker`.
2. Upload `index.html`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and wait for GitHub Pages to publish.
6. Submit the GitHub repository URL and live Pages URL if requested.
